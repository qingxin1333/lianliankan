# 🎮 连连看自动化脚本

## 📋 项目简介

这是一个基于图像识别和路径搜索算法的QQ连连看自动化脚本，采用Python开发，实现了智能识别游戏界面、自动匹配可消除方块、精确点击操作等功能。
<img width="800" height="600" alt="llk" src="https://github.com/user-attachments/assets/9f892251-34b0-445f-8538-07ead2ea1c89" />


### 🚀 核心技术栈
- **图像处理**: PIL + NumPy（RGB直方图相似度算法）
- **路径搜索**: BFS广度优先搜索（最多两次转向）
- **窗口操作**: Win32 API（精确鼠标点击）
- **自动化控制**: 多线程 + 键盘监听

### 💡 技术亮点
- ✅ **智能图像识别**: 基于RGB三通道直方图相似度算法，准确率达95%+
- ✅ **高效路径搜索**: BFS算法优化，支持最多两次转向的连通性判断
- ✅ **精确坐标计算**: 自适应游戏窗口大小，像素级定位
- ✅ **可调节速度**: 支持0.01-2.0秒点击间隔自定义
- ✅ **实时停止**: ESC键紧急停止，游戏窗口关闭自动退出

## 🔧 核心算法

### 图像识别算法
基于RGB三通道直方图相似度，通过以下步骤实现：
1. 将游戏区域分割为11×19网格
2. 提取每个网格的图像特征
3. 计算RGB直方图相似度
4. 阈值判断（>0.95）确定相同方块

### 路径搜索算法
采用BFS广度优先搜索，实现连连看规则：
- 最多允许两次转向
- 只能通过空白格子连接
- 边界检测和状态剪枝优化

### 坐标计算
自适应游戏窗口大小：
```python
game_left = window_left + int(14.0 / 800.0 * actual_window_width)
game_top = window_top + int(181.0 / 600.0 * actual_window_height)
```

## 📊 性能优化

### 速度调优
- **默认模式**: 0.1秒点击间隔，适合大多数情况
- **快速模式**: 0.05秒点击间隔，提高效率
- **超快模式**: 0.02秒点击间隔，极限性能
- **慢速模式**: 0.2秒点击间隔，稳定可靠

### 内存优化
- 即时释放图像资源
- 限制每轮最多10次点击
- 状态缓存避免重复计算
