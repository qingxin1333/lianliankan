# GitHub 上传命令 - 连连看自动化脚本项目
# 仓库地址: https://github.com/qingxin1333/lianliankan.git

# 1. 初始化 Git 仓库（如果还没有初始化）
git init

# 2. 添加远程仓库
git remote add origin https://github.com/qingxin1333/lianliankan.git

# 3. 添加所有文件到暂存区
git add .

# 4. 提交文件
git commit -m "Initial commit: 连连看自动化脚本

- 实现基于图像识别的连连看自动化
- 支持可调节点击速度
- 包含批处理启动器
- 完整的项目文档"

# 5. 推送到远程仓库（首次推送）
git push -u origin main

# 如果遇到分支名问题，可以使用以下命令：
# 查看当前分支
git branch
